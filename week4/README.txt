Week 4 inspection exercise

baseline/ contains an untouched copy of the supplied starter.
improved/ contains the guided inspection interface built from that copy.
week4.md is the report and observation worksheet.
images/ is for your screenshots and sketches.

To run both pages locally, open PowerShell at the repository root and run:

  Set-Location <repository-root>
  python -m http.server 8000

Then open:

  http://localhost:8000/week4/baseline/
  http://localhost:8000/week4/improved/

Record your actual baseline observations and comparison measurements in
week4/week4.md. Add your own screenshots and sketches under week4/images/.
The report intentionally does not invent times, operation counts, or
usability results.
