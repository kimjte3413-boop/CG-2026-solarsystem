## 관찰자와 설계 목표

- 사용자 및 상황: 시설을 처음 보는 점검자가 정보를 놓치지 않고 여섯 표지와 두 구조 비교를 확인한다.
- 우선 목표: 관찰 지점까지의 탐색 조작을 줄이고, 상세 화면에서도 전체 시설에서의 위치를 알 수 있게 한다.
- 함께 지킬 조건: 모델과 표지 데이터는 보존하고, 관찰 완료 여부는 직접 확인한 뒤 표시한다.

## 대안 비교와 선택

| 대안 | 줄일 수 있는 조작·유지되는 정보 | 단점·위험 |
|---|---|---|
| 목록에서 지점을 선택해 상세 카메라로 이동 | 수동 회전·확대·위치 찾기를 줄이고 지점별 표지와 주변 장치 관계를 크게 보여 줌 | 자유 시점 탐색과 같은 연속적인 시야 전환은 아님 |
| 전체 위치도와 상세 화면을 함께 표시 | 세부 정보와 전체 시설에서의 위치를 동시에 유지 | 위치도는 작고, 선택 지점 마커가 화면 비율 변화에도 정확히 맞아야 함 |
| 4분할 뷰 | 전체·정면·측면·상면을 한눈에 비교 | 각 화면과 명판이 작아지고, 뷰마다 입력·종횡비를 관리해야 함 |

대안 스케치(구현 전 비교):

```text
A. 네 방향 동시 보기                 B. 선택 지점 상세 + 전체 위치도
+---------+---------+                +-----------------------+------+
| 전체    | 정면    |                |                       | 지도 |
+---------+---------+                |   선택한 표지 상세    | 현재 |
| 측면    | 상면    |                |                       | 위치 |
+---------+---------+                +-----------------------+------+
| 글자·대상 크기가 작아짐             | 선택 목록 · 이전/다음 · 완료 |
```

선택·조합한 방식과 기본 버전의 관찰 근거: 설계 목표는 선택 목록으로 P1–P6에 바로 이동하고, 별도 위치도로 전체 맥락을 유지하며, O1/O2는 목적에 맞춘 직교 카메라로 비교하는 것입니다. 기본 버전에서 실제로 관찰한 불편과 캡처를 위에 기록한 뒤 이 선택의 효과를 확인합니다. 아직 채우지 않은 관찰 기록은 실제 테스트 후 작성합니다.

## 구현한 카메라와 인터페이스

- P1–P6은 표지의 위치와 방향에서 정면에 해당하는 쪽으로 카메라를 놓고, 표지 크기와 화면 비율을 기준으로 거리를 계산합니다. 프레임 높이가 표지 높이를 포함하고 가로 폭도 화면 안에 들어오도록 수평·수직 시야 조건 중 더 큰 거리 값을 택합니다.
- 상세 화면과 별도로 오른쪽 위에 시설 전체를 내려다보는 직교 위치도를 그려 현재 지점의 맥락을 유지합니다. 위치도 버튼은 전체도와 선택 마커의 표시를 함께 전환하며, 숨겨져 있을 때는 보조 뷰의 렌더링도 생략합니다.
- P2에서는 1층 전면 난간, P5에서는 뒤쪽 벽을 선택적으로 숨길 수 있습니다. UI에는 숨김/복원 상태가 표시됩니다.
- O1은 카메라를 건물 앞쪽 `+z`에 두고 `-z` 방향을 바라보며, `up=(0,1,0)`인 전면 직교 뷰를 사용합니다. 화면 가로축은 `x`, 세로축은 `y`입니다.
- O2는 건물 오른쪽 `+x`에 카메라를 두고 `-x` 방향을 바라보며, 같은 up 벡터의 측면 직교 뷰를 사용합니다. 화면 가로축은 `z`이므로 `+z` 쪽이 화면 왼쪽에 놓입니다.
- O1/O2의 직교 배율은 두 비교 대상의 월드 단위 경계와 현재 화면 비율에서 계산합니다. 대상마다 개별 확대하지 않으므로 한 비교 화면 안에서 두 물체의 크기를 직접 비교할 수 있습니다.
- 두 직교 비교와 여섯 표지 관찰은 선택 목록에서 전환하며, 전체 보기로 돌아가거나 자유 회전으로 이어서 탐색할 수 있습니다.
- O1 모델의 두 패널은 모두 `1.2 × 1.6 m`여서 상단 높이와 폭이 같습니다. O2는 파랑 A의 앞끝이 `z=1.0 m`, 주황 B가 `z=0.4 m`이므로 A가 `+z` 쪽으로 `0.6 m` 더 나옵니다. 이는 모델 값으로 계산한 교차 확인이며, 화면에서 직접 비교하는 과제를 대신하지 않습니다.

대표 코드 위치: `improved/d04-inspection-student.js`의 `focusCamera`, `comparisonCamera`, `drawContextMap`, `viewer.render`.

## Copilot 제안과 판단

- 검토한 대안: 4분할 뷰, 선택 지점으로 바로 이동, 전체 위치도와 상세 화면의 동시 표시, P2/P5 가림 구조물 숨김.
- 채택·수정·거절한 결정: 선택 목록·대상 크기에 맞춘 원근 상세 카메라·위치도·O1/O2 직교 비교를 조합했습니다. 모든 뷰가 작아지는 4분할 대신 한 번에 한 과제를 크게 보여 주고, 자유 회전과 전체 보기로 이어갈 수 있게 했습니다. 가림 구조물은 P2/P5에서만 선택적으로 숨기며 상태 표시와 복원 버튼을 제공합니다.
- 판단 근거 및 실행으로 확인한 결과: 로컬에서 기본·개선 페이지와 WebGL2 렌더링을 확인했습니다. P1–P6/O1/O2가 각각 선택되고, O1은 높이·폭 두 답을 모두 고르기 전에는 완료되지 않으며 O2도 비교 답을 선택해야 완료됩니다. 측정 시간·사용자 경험·기본 대비 조작 절감은 실제 사용 후 기록합니다.
