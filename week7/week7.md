## 실습 1 — 기본 ray tracing으로 일식·월식

전체 화면 사각형의 각 프래그먼트에서 카메라 광선을 만들고, 광선과 별·행성·위성 구 및 방 바닥·뒷벽의 교차 거리 중 가장 가까운 양수를 고릅니다. 행성에는 위도 방향 줄무늬를 적용했고, 바닥과 뒷벽에는 공간 격자를 표시했습니다. 이 장면은 구 메시 래스터화가 아니라 프래그먼트 셰이더의 `sphereHit()`, `traceBodies()`, `traceRoom()`으로 계산합니다.

천체 표면과 바닥의 직접광은 별 방향의 `dot(N, L)`로 계산합니다. 그림자 광선을 켜면 교차점에서 별까지 다른 천체가 있는지 다시 검사합니다. 공전 위치 0°에서는 위성이 별과 행성 사이에, 180°에서는 행성 뒤에 놓입니다. 달의 주변광은 월식 때도 윤곽을 관찰할 수 있도록 남긴 교육용 근사이며, 행성 대기의 붉은 굴절광을 계산하지는 않습니다.

## 실습 2 — Local·ray·path 화질과 성능

같은 구와 바닥 장면을 세 방식으로 표시합니다. Local은 구 메시와 바닥 삼각형을 WebGL 래스터화로 그리며 직접 조명을 계산합니다. 기본 ray tracing은 픽셀 광선과 장면 교차, 그림자 광선을 검사합니다. Path tracing은 픽셀마다 확산 방향을 무작위 표본 추출하고 설정한 최대 반사 횟수까지 경로를 이어 평균합니다. 고급 효과는 ray/path 방식의 거울 반사와 유리 굴절 경로를 추가합니다. Local은 직접 조명만 사용하므로 거울·유리 반사를 계산하지 않습니다.

해상도(320×180부터 1920×1080), 표본(4–32), 최대 반사(1–4), 고급 효과를 각각 조절할 수 있습니다. 「세 방식 3회 측정」은 각 방식의 중앙값을 표시합니다. GPU 타이머 확장을 쓸 수 있으면 GPU 실행 시간과 `gl.finish()` 동기화를 포함한 시간 둘 다 표시하고, 지원되지 않으면 GPU 시간을 `—`로 둡니다. 두 시간 열은 서로 다른 측정이므로 혼합해 비교하지 않습니다.

첫 방문에서는 현재 브라우저에서 작은 path tracing 장면을 측정해 초기 프로필을 선택합니다. 설정은 기기 등급과 브라우저별 `localStorage` 키에 저장하고, 사용자가 설정을 바꾸면 다음 방문에도 적용합니다. 이는 서로 다른 실제 기기에서의 측정을 대신하지 않습니다.
